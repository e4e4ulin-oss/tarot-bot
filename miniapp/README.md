# Колода как мини-приложение Telegram

Статическая страница: `index.html`, описания карт в `cards.json`, лица в `cards/`,
рубашки в `backs/`. Ни сборки, ни сервера приложению не нужно — только раздача
файлов по https. Внутри Telegram подхватывается `telegram-web-app.js`: страница
разворачивается на весь экран, системная кнопка «назад» закрывает разворот карты,
на переворот отвечает короткая вибрация. В обычном браузере всё это молчит, и
страница работает как есть.

## Посмотреть локально

    cd miniapp && python3 -m http.server 8000

Откройте `http://localhost:8000`. Telegram локальный адрес не примет — ему нужен
https, — но вёрстку и колоду так смотреть удобнее всего.

## Опубликовать

Нужен любой хостинг статики с https. Два очевидных пути:

**На своём сервере, рядом с ботом.** Папка кладётся в `/var/www/taro`, nginx
раздаёт её, сертификат берётся у Let's Encrypt:

    server {
        listen 443 ssl;
        server_name taro.example.com;
        root /var/www/taro;
        add_header X-Robots-Tag "noindex" always;
    }

**Через GitHub Pages.** Включается в настройках репозитория, источник — ветка
`miniapp`, папка `/miniapp`. Бесплатно, https из коробки; для закрытого
репозитория нужен платный план.

Страница отдаётся с `noindex`: колода не должна попадать в поиск.

## Подключить к боту

1. Положите адрес в окружение бота:

        MINIAPP_URL=https://taro.example.com

2. Перезапустите бота. Команда `/deck` начнёт отвечать кнопкой «Открыть колоду».
   Без адреса команда честно говорит, что колода не опубликована.

3. Чтобы кнопка появилась ещё и в меню рядом со скрепкой, напишите @BotFather:
   `/mybots` → ваш бот → *Bot Settings* → *Menu Button* → *Edit menu button URL*,
   и дайте тот же адрес.

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | вся страница: вёрстка, стили и логика в одном файле |
| `cards.json` | 78 карт: имя, краткое и полное описание, масть, номер |
| `cards/` | лица нарисованных карт, 720×1080 |
| `backs/` | рубашки по мастям |

Ненарисованная карта показывается пустым полем своего цвета — доска не ломается
и видно, сколько осталось.
