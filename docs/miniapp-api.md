# Мини-приложение с функциями бота

Колода в приложении открывается без сервера: это файлы. Всё остальное, что
умеет бот, — расклад, карта дня, кабинет, история — живёт в процессе с базой,
и страница сама по себе до него не достучится. Браузер не выпустит запрос со
страницы `https` на адрес `http`, а WebView Telegram — это браузер.

Поэтому работа делится надвое: сначала у сервера появляется имя и сертификат,
потом у бота — API, и только потом у страницы экраны.

## 1. Имя и сертификат (делается один раз)

Домена у проекта пока нет, и покупать его не обязательно: бесплатный поддомен
даёт настоящий сертификат Let's Encrypt.

1. Открыть [duckdns.org](https://www.duckdns.org), войти любым из предложенных
   способов — Telegram там нет, подойдёт Google или GitHub.
2. В поле `sub domain` придумать имя, например `taroautorasklad`, нажать
   **add domain**.
3. В строке появившегося домена вписать адрес сервера `82.38.171.139`
   и нажать **update ip**.
4. На сервере выполнить:

       sudo bash /opt/tarot-bot/deploy/web.sh taroautorasklad.duckdns.org почта@пример.рф

Скрипт ставит nginx, настраивает сайт, берёт сертификат и включает продление.
Перед установкой он проверяет, что имя и правда ведёт на этот сервер: без этого
certbot откажет позже и непонятнее.

Получится одно имя и на страницу, и на API:

    https://taroautorasklad.duckdns.org/        колода (файлы из miniapp/)
    https://taroautorasklad.duckdns.org/api/…   бот

Одно имя на двоих выбрано не случайно: страница и API оказываются на одном
источнике, и в браузере не возникает ни CORS, ни отдельных настроек.

Сертификат привязан к имени, а не к адресу: когда появится свой домен, меняется
одна строка, код не трогается.

## 2. Что остаётся на GitHub Pages

Ничего обязательного. Страница с сервера — та же самая папка `miniapp`,
обновляется вместе с кодом бота. Pages можно оставить витриной или выключить.

## 3. Правила не раздваиваются

Расклад из приложения идёт через те же `bot/services/reading.py`, что и расклад
из чата: доступ, лимиты, оплата и число, под которое ложатся карты. Если бы
приложение считало это само, через месяц в нём оказалось бы больше бесплатных
раскладов, и узналось бы это по выручке, а не по тесту.

## 4. Кто пришёл

Telegram отдаёт странице подписанные данные о пользователе (`initData`).
Сервер проверяет подпись токеном бота — и знает номер человека, не спрашивая
его ни о чём. Для франшизы это же решает вопрос арендатора: у каждого бота свой
токен, и подпись сама говорит, чей это клиент.
