# Оформление бота в BotFather

Десять минут один раз. Всё ниже — готовые тексты: откройте @BotFather, выберите
команду, вставьте текст. Менять можно сколько угодно раз.

## 1. Описание — что видно до запуска

`/setdescription` → выбрать бота → вставить:

```
Расклады Таро в Telegram. Автоматический расклад с разбором — бесплатно и сразу.
Авторский разбор — карты раскладывает и разбирает человек, ответ приходит в этот чат.
```

Это текст на пустом экране с кнопкой «Начать»: человек читает его до первого
сообщения. Коротко и без обещаний, которых бот не выполняет.

## 2. Краткое описание — в профиле и в поиске

`/setabouttext` → вставить (лимит 120 символов):

```
Расклады Таро: авто-расклад с разбором бесплатно, авторский разбор — от 500 ₽.
```

## 3. Картинка

`/setuserpic` → отправить квадратное изображение, минимум 512×512.

Что подойдёт: одна карта крупным планом, разложенные карты на ткани, рука над
картами. Без текста на картинке — в кружке аватара он нечитаем.

## 4. Команды в меню

`/setcommands` → вставить **одним сообщением**:

```
start - Меню
help - Как пользоваться
cancel - Отменить текущее действие
```

Админские команды (`/orders`, `/stats`, `/update`, `/logs`, `/restart`) сюда
вносить не нужно: они и так работают, но в списке их увидят все.

## 5. Кнопка «Начать»

`/setinline` не нужен. А вот текст кнопки в пустом чате задаётся так:

`/mybots` → выбрать бота → `Bot Settings` → `Menu Button` → `Edit menu button text`:

```
Открыть меню
```

## 6. Ссылка, которую можно давать людям

```
https://t.me/Taroautorasklad_bot
```

Её же можно положить в описание канала, в личный профиль, отправить знакомым.

---

## Что проверить после оформления

1. Открыть ссылку в режиме инкогнито (или попросить знакомого) — увидеть описание
   и кнопку «Начать».
2. Нажать «Начать» — прийти в меню.
3. Сделать авто-расклад целиком, как обычный человек.
4. Открыть авторский разбор и дойти до подтверждения заявки, не отправляя её.

Если на каком-то шаге стало скучно или непонятно — это и есть то место, где будут
отваливаться люди. Скажите, какое именно, и мы его перепишем.
